# XA counterweight and tonearm rest

[Part index](reproduction.md) · [XA](../models/xa/README.md) · [Things to confirm](../TO-CONFIRM.md#counterweight-and-rest)

Owner report: **patrickhenrypdx**, measured on their own XA. [Original post](https://www.reddit.com/r/turntables/comments/1t5vqzh/ar_xa_tone_arm_counter_weight_tone_arm_rest/). No tolerances were given.

## Counterweight

| Feature | Reported value |
| --- | --- |
| Outside diameter | 28 mm |
| Length along bore | 22 mm |
| Bore diameter | 9.5 mm |
| Mass, including set screw | 98.8 g |
| Material | Brass |

Needed for a drawing: bore fit on the arm stub, bore centering, locking-hole thread and position, screw tip and length, edge details, mass range. A [preliminary drawing](../cad/exports/xa-counterweight/PRELIMINARY-xa-counterweight.pdf) and [STEP file](../cad/exports/xa-counterweight/PRELIMINARY-xa-counterweight.step) use these values.
