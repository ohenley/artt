# XA mods

[XA](../README.md) · [Parts and makers](../../../parts/README.md) · [Things to confirm](../../../TO-CONFIRM.md) · [Home](../../../README.md)

Upgrades for anyone restoring an XA. Each page says if a mod also applies to the XB or later models. **None of these has been built or tested for this repository.** Values come from a cited source or are marked "to confirm on the part", and open items are in the [confirmation list](../../../TO-CONFIRM.md#xa-mods).

## Mods

- [RCA jacks in the plinth](rca-jacks.md): Stop a stiff interconnect from loading the subchassis.
