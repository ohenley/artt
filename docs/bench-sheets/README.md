# Bench sheets

[Home](../../README.md) · [Things to confirm](../../TO-CONFIRM.md) · [Documents](../README.md)

One printable page per table. Each gathers the open rows in [Things to confirm](../../TO-CONFIRM.md) that one table can settle, in the order you meet the parts when opening it, with the tool and a blank for the result.

- [AR77XB](ar77xb.md): closes HS5, EL5, DM3 and MD10, the counterweight (CW13), and records headshell mass, badge and base material.
- [XB](xb.md): platter height, counterweight, capacitor markings, the TT-XBU labels, shell interchange with the XA.
- [XA](xa.md): counterweight, headshell, motor and capacitors by serial, base and plinth dimensions for the CAD models.

After a session, copy each result into the Result column of its row, with the model, serial and date, and set the status: Confirmed, or Differs.
